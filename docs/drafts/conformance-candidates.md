## 進め方の案

1. p0.4.3 の起草（立法補佐）に #1・#10 を足す（#1 は release.sh の最後で `update_board`、#10 は Codex の起動前の確認）
2. #2〜#5 は「限界の確認」として試験に入れ、通ることで限界を明文化する（直すのは次の版）
3. #16 は V8 の実施（オーナーの端末）で確かめる。今夜は昼の作業員で回したため夜間の代行の記録はない
4. 新しい試験はすべて、前の版（p0.4.2）にかけて**新しい規則の試験だけが落ちる**ことを確かめる（SPEC §11）
