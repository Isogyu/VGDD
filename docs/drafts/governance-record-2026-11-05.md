## 3. 言えること・言えないこと

**言えること（票の記録から）**
- 12 票すべてが、仕様の承認 → 作業員の実装 → 2系統の司法の判定 → オーナーの release の順で main に入った。この順を飛ばした票はない（T-015・T-016 は起動が承認の前だったが、統合は承認の後）
- 差し戻し 7 件のうち、コードの欠陥は 3 件。残りは票の書き方・票にない追加・環境・夜間の制約で、**司法が差し戻すことで票や環境の問題が見つかった**（統制の副産物）
- judge と Codex の不一致 3 件は、いずれもオーナーが裁定した。2 件は司法の誤検知（架空のメール、差分の外の条件）、1 件は Codex が正しかった（stale の操作）
- 作業員の実装は 1票 2〜10 分で、全体の時間の大半は判定（3〜5 分）・伝達・承認の待ちだった

**言えないこと**
- 司法の判定の全文・findings の数・`gate_events.jsonl` の件数（Z3。立法補佐の集計を待つ）
- VGDD なし（単一の AI、普通のマルチエージェント）との比較（対照がない。比較実験の計画は `docs/drafts/comparison-experiment.md`）
- 1票あたりの費用（トークン）。作業員の `usage` は会話に出るが票には書いていない。OTel（V4）は未実装
- 差し戻しがなければ品質が低かったか（差し戻された欠陥の深刻さは、T-015 の辞書と T-014 の stale は本番で再現しうる不具合、T-011 の NaN は入力の検証で防げる種類）
